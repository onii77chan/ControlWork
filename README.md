# Удобный конвертер файлов (Telegram-бот на Rust)

Продвинутый Telegram-бот для конвертации различных файлов, написанный на Rust. Бот может принимать изображения, видео, аудио и документы (включая группы файлов), предлагать доступные форматы для конвертации и отдавать результат без использования веб-серверов.

## Архитектура
1. **Rust-приложение (`src/main.rs`)**:
   - Отвечает за всю логику Telegram, используя `teloxide`.
   - Поддерживает машину состояний (FSM) для работы с пользователями (включая альбомы через сбор `media_group_id`).
   - Нативно конвертирует изображения через крейт `image`.
   - Вызывает `ffmpeg` напрямую из консоли для работы с аудио и видео (например: `mp4` <-> `mp3`).
   - Управляет внешним Python-скриптом для конвертации сложных документов (`pdf`, `docx`, `md`, `html`).
   - Сохраняет временные файлы в директорию `temp/` и очищает её после отправки результата.

2. **Python-скрипт (`convert.py`)**:
   - CLI-утилита для сложных конвертаций документов.
   - Использует `pdf2docx`, `mammoth` с `xhtml2pdf` и `pandoc`. Оптимизировано для работы в окружениях без графических зависимостей, таких как Termux на Android.

## Структура директорий
```
.
├── Cargo.toml            # Настройки и зависимости Rust-проекта
├── README.md             # Этот файл
├── requirements.txt      # Зависимости Python-скрипта
├── convert.py            # Python-скрипт для конвертации документов
├── src/
│   └── main.rs           # Главный файл с логикой Rust-бота
└── temp/                 # Временная директория для загрузки и конвертации файлов (создается автоматически)
```

## Требования

Перед запуском убедитесь, что в системе установлены:
- [Rust](https://rustup.rs/) (cargo)
- Python 3.x
- [FFmpeg](https://ffmpeg.org/) (должен быть доступен в переменной `PATH`)
- [Pandoc](https://pandoc.org/) (для конвертации различных текстовых форматов через Python)

## Настройка и запуск

1. Установите зависимости для Python:
   ```bash
   pip install -r requirements.txt
   ```

2. Установите токен вашего Telegram-бота в переменные окружения.
   Для Linux/macOS:
   ```bash
   export TELOXIDE_TOKEN="ВАШ_ТОКЕН_БОТА"
   ```

   Для Windows (PowerShell):
   ```powershell
   $env:TELOXIDE_TOKEN="ВАШ_ТОКЕН_БОТА"
   ```

3. Запустите Rust-бота:
   ```bash
   cargo run --release
   ```

## Использование
- Найдите бота в Telegram, нажмите "Старт".
- Отправьте боту один или несколько файлов (в виде альбома/media group).
- Бот проанализирует расширения и предложит список доступных форматов конвертации в виде inline-кнопок.
- Выберите формат, и бот выполнит работу и пришлет готовые файлы обратно.
